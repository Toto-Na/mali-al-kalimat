# مَلّي الكلمات — React Multiplayer

نسخة Multiplayer حقيقية مبنية بـ React + Node.js + WebSocket.

## التشغيل المحلي

```bash
npm install
npm run dev
```

للتشغيل كخادم واحد (بعد بناء React):

```bash
npm install
npm run build
npm start
```

ثم افتحي `http://localhost:8787`.

## النشر المجاني على Render

المشروع يحتوي `render.yaml` جاهزًا.

1. ارفعي المشروع إلى GitHub.
2. في Render اختاري New > Blueprint.
3. اختاري مستودع GitHub.
4. سيقرأ Render `render.yaml` ويشغل:
   - Build: `npm install && npm run build`
   - Start: `npm start`
   - Health: `/health`

في الإنتاج لا تحتاجين إلى `VITE_SERVER_URL` لأن Node يخدم React وWebSocket من نفس الرابط.

## مميزات Multiplayer

- إنشاء غرفة برمز من 6 أحرف.
- حتى 20 لاعبًا في الغرفة.
- أسماء اللاعبين تظهر لحظيًا.
- رابط دعوة يحتوي رمز الغرفة، ويمكن فتحه من أي هاتف.
- يمكن وضع `name` في الرابط ليتم تعبئته تلقائيًا، مثل:
  `?room=ABC123&name=سارة`
- المضيف ينتقل تلقائيًا للاعب آخر عند خروجه.
- الجولة والوقت والحرف تأتي من السيرفر، وليس من جهاز اللاعب.
- تسليم الإجابات مرة واحدة فقط.
- انتهاء الجولة تلقائيًا عند انتهاء الـ60 ثانية أو عند تسليم الجميع.
- النتائج والنقاط محسوبة على السيرفر.
- زر مشاركة مناسب للجوال وCapacitor.
- PWA وCapacitor جاهزان للتغليف كتطبيق Android.

## APK

بعد تثبيت Android SDK وJava/Android Studio:

```bash
npm install
npm run android:add
npm run android:build
```

سيكون ملف Debug APK داخل:

`android/app/build/outputs/apk/debug/app-debug.apk`

> ملاحظة: الغرف الحالية مؤقتة في ذاكرة السيرفر. هذا مقصود للعبة؛ إذا توقف السيرفر تنتهي الغرف. لا تحتاج قاعدة بيانات لنسخة اللعب اللحظي الأساسية.


## إصلاحات مهمة في هذه النسخة
- `server.js` يعمل بصيغة ES Modules المتوافقة مع `type: module` في package.json.
- تمت إضافة مزامنة حقيقية للعد التنازلي من السيرفر.
- عند النشر على Render يستخدم المتصفح `wss://` تلقائيًا.
- يمكن ضبط `VITE_SERVER_URL` إذا كان WebSocket على نطاق منفصل.

## إضافات v4
- المضيف يستطيع إضافة أو حذف أعمدة قبل بدء الجولة، حتى 12 عمودًا.
- الأعمدة الجديدة تصل لحظيًا إلى جميع اللاعبين.
- النتائج تظهر لجميع اللاعبين بعد انتهاء الجولة.
- نتائج كل لاعب تعرض كل إجابة، النقاط، والتفسير: صحيحة، مكررة، فارغة، حرف واحد، أو لا تبدأ بالحرف.
- الإجابة المكونة من حرف واحد فقط = 0 نقطة.
- الإجابة الفارغة = 0 نقطة، ويظهر للاعب تنبيه قبل التسليم مع خيار العودة أو التسليم رغم الفراغ.
- إجابة صحيحة وفريدة = 10 نقاط، والمكررة بين لاعبين في نفس العمود = 5 نقاط لكل لاعب.
